# Superstore Sales Analysis Dashboard (Power BI)

## Project Overview

This project analyzes sales performance using the Sample Superstore dataset in Power BI. The objective is to create an interactive dashboard that presents key business insights through effective data visualization and storytelling.

## Tools Used

* Power BI Desktop
* Sample Superstore Dataset (CSV)

## Dashboard Components

### KPI Cards

The dashboard includes the following Key Performance Indicators (KPIs):

* Total Sales
* Total Profit
* Total Orders
* Total Quantity Sold

### Visualizations

#### 1. Sales by Category

* Clustered Bar Chart
* Compares sales across Furniture, Office Supplies, and Technology categories.

#### 2. Profit by Category

* Clustered Column Chart
* Shows profitability of each product category.

#### 3. Monthly Sales Trend

* Line Chart
* Analyzes sales performance over time using Order Date hierarchy (Year and Month).

#### 4. Sales by Region

* Bar Chart
* Compares sales across different regions.

#### 5. Segment Analysis

* Donut Chart
* Displays sales contribution from Consumer, Corporate, and Home Office segments.

#### 6. Top 10 Customers

* Bar Chart
* Highlights the top 10 customers based on total sales.

## Interactive Filters (Slicers)

The dashboard includes the following slicers:

* Region
* Category
* Segment
* Order Date

These filters allow users to interactively explore the data and customize the analysis.

## Key Insights

* Sales performance varies across product categories.
* Profitability differs among categories despite similar sales volumes.
* Regional sales analysis helps identify high-performing markets.
* Consumer segment contributes a significant portion of total sales.
* A small group of customers generates a large share of revenue.
* Monthly sales trends help identify growth patterns and seasonal behavior.
